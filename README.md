# Simple RPG 🗡️🛡️

A lightweight, console-based Role-Playing Game (RPG) built in C++ for fun, exploration, and turn-based combat. Embark on a quest, defeat monsters, level up your hero, and collect epic loot directly from your terminal!

---

## 🚀 Features

- **Character Creation:** Name your hero and roll initial stats.
- **Turn-Based Combat:** Tactical battles against various enemies using a classic text-based menu.
- **Inventory & Equipment:** Manage your weapons, armor, and healing items.
- **Leveling System:** Gain XP from victories.
- **Memory Safe:** Clean object-oriented C++ design.
